# SocialX original instrumentals

Daylight, Nightwalk, and Spark are synthesized by `scripts/generate-music.cjs`.
They contain no third-party samples, vocals, recordings, or deliberately copied melodies.
The project may bundle these generated recordings and use them in users' reels and exports.
These are original starter instrumentals, not licensed commercial songs. No promise is made
that an external platform's automated audio matching system will never flag a recording.

Rebuild the WAV files with `node scripts/generate-music.cjs`.
